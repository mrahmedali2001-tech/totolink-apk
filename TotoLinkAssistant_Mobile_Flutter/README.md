# TotoLink Assistant Mobile (Flutter -> APK)

## طريقة استخراج ملف APK مجاناً بدون تثبيت أي برامج:
1. أنشئ مستودع (Repository) جديد على حسابك في GitHub.
2. ارفع جميع الملفات الموجودة في هذا المجلد (بما فيها مجلد `.github` المخفي).
3. انتقل إلى تبويب **Actions** في المستودع على GitHub.
4. اختر **Build Android APK** ثم اضغط **Run workflow**.
5. بعد دقيقتين ستجد ملف **TotoLinkAssistant-APK** في أسفل الصفحة جاهزاً للتحميل وتثبيت `app-release.apk` على هاتفك.
